## Installation [Windows ](https://wikipedia.org/wiki/Microsoft_Windows)[![alt tag](http://icons.iconarchive.com/icons/tatice/cristal-intense/32/Windows-icon.png)](https://fr.wikipedia.org/wiki/Microsoft_Windows)

```
git clone https://github.com/Mav3r1ck0x1/TeleKiller.git
cd TeleKiller

mkdir C:\py34pkgs
cd C:\py34pkgs

Download "pyHook_3k_compiled-1.5.1-cp34-cp34m-win_amd64.whl" and rename to "pyHook-1.5.1-cp34-none-win_amd64.whl"  (https://pypi.org/project/pyHook-3k-compiled/)

Download other required packages:
curl -L https://files.pythonhosted.org/packages/source/a/altgraph/altgraph-0.13.tar.gz -o altgraph-0.13.tar.gz
curl -L https://files.pythonhosted.org/packages/source/c/colorama/colorama-0.3.7.tar.gz -o colorama-0.3.7.tar.gz
curl -L https://files.pythonhosted.org/packages/source/d/dis3/dis3-0.1.3.tar.gz -o dis3-0.1.3.tar.gz
curl -L https://files.pythonhosted.org/packages/source/f/future/future-0.16.0.tar.gz -o future-0.16.0.tar.gz
curl -L https://files.pythonhosted.org/packages/source/m/macholib/macholib-1.7.tar.gz -o macholib-1.7.tar.gz
curl -L https://files.pythonhosted.org/packages/source/p/pefile/pefile-2016.3.28.tar.gz -o pefile-2016.3.28.tar.gz
curl -L "https://files.pythonhosted.org/packages/7d/ab/f593fcdb932240463fa4e65d1d6f96eb342f265e6fe3c8f19a692586ce77/pywin32-ctypes-0.0.1.tar.gz" -o pywin32-ctypes-0.0.1.tar.gz

curl -L "https://files.pythonhosted.org/packages/3f/d2/3515242cc5cfed12706506d17728a7ee0b8cf33840e250357fd793a94607/PyInstaller-3.2.1.tar.bz2" -o PyInstaller-3.2.1.tar.bz2
curl -L -o pypiwin32-219-cp34-none-win_amd64.whl "https://files.pythonhosted.org/packages/8f/da/36439654abd8f39bcad0664c68674a41b838ca902da440defde17abbeade/pypiwin32-219-cp34-none-win_amd64.whl"

Install required packages:
py -3.4 -m pip install altgraph-0.13.tar.gz
py -3.4 -m pip install colorama-0.3.7.tar.gz
py -3.4 -m pip install dis3-0.1.3.tar.gz
py -3.4 -m pip install future-0.16.0.tar.gz
py -3.4 -m pip install macholib-1.7.tar.gz
py -3.4 -m pip install pefile-2016.3.28.tar.gz
py -3.4 -m pip install pywin32-ctypes-0.0.1.tar.gz
py -3.4 -m pip install pypiwin32-219-cp34-none-win_amd64.whl --no-index
py -3.4 -m pip install PyInstaller-3.2.1.tar.bz2 --no-index

cd ..
python TeleKiller.py
```
## Dependency :

- [x] python 3.4
- [x] pyHook_3k_compiled-1.5.1-cp34-cp34m-win_amd64.whl
- [x] pywin32
